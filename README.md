## Make everyday adventures count

- **Seven activity tracks:** mining, combat, fishing, farming, crafting, engineering and exploration.
- **A character of your own:** personal levels, a milestone journal, titles and a compact optional HUD.
- **A meaningful skill budget:** up to 175 earned points at level 100, with an external Pufferfish Skills tree.
- **A connected party:** optional FTB Teams milestone sharing while character XP stays personal.
- **Pack author controls:** configurable activity curves, unlock ceilings, mob scaling and quest rewards.

## Open your character sheet

Press **I**, or click the **player portrait** in the survival inventory. Review your activity progress, pin a track to the HUD, equip a title, or open the configured skill tree. Change the key in Controls → Towns & Kingdoms.

Install matching versions on **client and server** with **Minecraft 1.21.1, NeoForge 21.1.262+ and Java 21**. The public source on this branch is **0.6.0-beta.1**. The 588-node skill tree is supplied as external `config/puffish_skills/` files; install the matching configuration alongside the JAR.
