# Towns & Kingdoms Progression

Earn character XP from combat, mining, farming, cooking, fishing, exploration, and quest rewards. Choose an origin, unlock titles, and fight mobs that scale with your level.

**Requires** Minecraft 1.21.1, NeoForge 21.1.262 or newer, and Java 21.

[CurseForge](https://www.curseforge.com/minecraft/mc-mods/towns-kingdoms-progression)
