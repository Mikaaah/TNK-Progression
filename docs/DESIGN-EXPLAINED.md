# What the remaining design work means

These six topics are explanations and design proposals, not features implemented by the 0.2.0 activity update.

1. **Just Leveling-style aptitudes and titles.** Aptitudes would represent what a character is good at, such as mining proficiency, endurance or spell handling. They could give small passive bonuses or unlock conveniences at milestones. Titles are earned labels such as Engineer or Champion. An activity title can depend on profession history; a campaign rank should depend on quest milestones. Neither requires the Just Leveling mod. Avoid adding another spendable point pool until its purpose is clear: character level, activity ranks, skill purchases and campaign ranks already have distinct jobs. The supplied rank artwork can support quest titles later.

2. **Character screen, XP HUD and activity journal.** A character screen would collect level, current/required character XP, unlocked ceiling and its quest, total skill entitlement, and future rank/class in one menu. The HUD would provide a compact optional character-XP bar, brief XP gain notices and a clear capped state. The journal would list the seven activities, current milestone work/requirement, next XP reward and recent milestones, with reasons ineligible actions did not count. These are interfaces over saved progression, not extra XP systems. `/tnkprogress status` and the new `/tnkprogress activities` are the current text views; no custom GUI/HUD is included here.

3. **Campaign quests and world events.** FTB Quests defines what players must actually achieve: build a working production line, finish a boss chain, restore a structure, or complete an expedition. A world event is an authoritative server condition such as defeating a specified boss or defending a settlement. The progression mod receives unlock/XP commands after success. The pack already has ten production chapters; the new optional bridge awards engineering commissions against their existing completion IDs. It does not redesign quests or connect the seven default character ceilings to all ten chapters. Current chapter completion checkmarks are manually confirmed, so automatic factory validation would need additional objectives/logic. Quest rank and personal character level should remain separate.

4. **Identification-cost and salvage-bonus nodes.** These would connect purchased Pufferfish nodes to Unidentified Loot operations. For example, a node could reduce the final vanilla-XP identification cost by 5%; a salvage keystone could give a carefully limited extra material chance. These discounts must be calculated on the server before checking/payment, use exactly the same displayed and charged cost, and preserve defined minimum costs. Salvage bonuses must exclude recursive self-funding returns. Refund/respec must immediately remove the effect. They must not change sealed tier/rarity or bypass quest gates. The current Artificer nodes still use anvil/orb-XP/tool attributes; those custom hooks are not included in this update.

5. **Conditional abilities such as Second Wind.** These are event-triggered passives rather than permanent attributes. An example proposal: while the node is active, dropping below 25% health grants a brief defensive benefit with a 120-second cooldown. Exact values are undecided. The server must test a real damage event, check ownership/cooldown, apply the effect once and persist the cooldown across reconnects/respawns so it cannot reset through relogging. The ability must stop being available after respec and must specify how it interacts with death prevention and other mods. No Second Wind effect is added here.

6. **Final balance: XP, mobs, loot and passives together.** XP pacing sets intended time to each level and the effort/reward of every activity and quest. Mob balance sets the health, attack and difficulty appropriate to dimensions/locations and player gear. Loot balance sets the 2% equipment roll, available item pools, equipment tier/rarity and progression gates. Passive balance checks the sum of 100 selected nodes with Apotheosis affixes and magic attributes, rather than tuning one node in isolation. Run early/mid/endgame builds through representative combat, mining, fishing and factory sessions; compare time-to-level, time-to-kill/death, useful drops per hour and best skill combinations. The activity update adds sources and guardrails; the old character-XP curve, loot tier table, drop chances and skilltree stats have not been declared final or globally retuned.
