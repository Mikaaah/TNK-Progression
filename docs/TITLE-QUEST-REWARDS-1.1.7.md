# TNK Progression 1.1.7 quest title rewards

In FTB Quests, add each command as an automatic **Command Reward** with **permission level 2**. Paste the command without a leading slash. `{p}` resolves to the player receiving the reward. Keep **Team Reward** disabled so each player can earn the title. The mod supplies the titles. The quest book needs the corresponding command rewards to award them.
