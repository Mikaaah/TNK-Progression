# Colored skill tooltips

The external Pufferfish tree now uses native Minecraft JSON text components:

- Bold gold skill names and title unlocks.
- Bold lavender branch and subclass names.
- Soft green effect text.
- Muted warm gray conditions and supporting details.
- Lavender shared mana notes.

All 588 nodes retain the same visible wording, line wrapping, bonuses, costs,
requirements and IDs. The color pass changes presentation only.

Install the supplied `config/puffish_skills` files on the server and clients.
This works with the existing TNK Progression 0.6.0-beta.1 JAR. Restart the game
or reload the server configuration after replacing the files.
