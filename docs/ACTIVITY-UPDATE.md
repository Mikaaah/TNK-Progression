# Activity coverage — 1.1.0

Progression now awards **direct character XP** from combat, natural mining, farming, cooking, fishing, exploration and quest rewards. There are no separate activity levels or escalating milestone requirements. Automatic crafting and engineering XP have been removed.

The authoritative current tables, event rules, anti-farm boundaries and server settings are in [Direct character XP](DIRECT-XP.md). The in-game activity Info buttons reflect the server’s active rules.
