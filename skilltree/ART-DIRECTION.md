# Warm-brown character theme

The background texture is `resourcepack/assets/tnk/textures/gui/character_background.png`.

Use an opaque, nearly uniform warm brown around sRGB `#594936`, with very subtle paper grain. Keep it free of scenery, lettering, frames and decorative objects so the skill nodes remain readable.

Retain the native 26-pixel bronze, violet and gold frames and their five visual states. The HAS icon artwork remains unchanged. For the current tree layout and point entitlement, use [the rebuilt tree reference](rebuilt588/README.md).
